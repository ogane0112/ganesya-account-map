# v1 実装スコープ定義書

- 版数: v1.0
- 作成日: 2026-08-08
- 元資料: [要件定義書 v0.4](../01_requirements/requirements.md)

## 1. 目的

要件定義書の内容は将来拡張分も含んでいるため、本書で「個人利用の初期リリース(v1)」として
実装する範囲と、次フェーズ以降に持ち越す範囲を明確にする。以降の基本設計・詳細設計・実装は
本書のスコープに基づいて行う。

## 2. v1で実装する機能

| # | 要件定義書の項番 | 機能 | 実装方針 |
|---|---|---|---|
| 1 | 5.1 | アカウント登録・一覧・詳細・編集・削除・検索・フィルタ・ソート | フル実装 |
| 2 | 5.2 | ログイン方式(ID_PW/OAuth/SNS/Card/Device)の複数登録 | フル実装 |
| 3 | 5.3-a | パスワード保存先(credential_manager)の選択式記録 | フル実装(値そのものは保存しない) |
| 4 | 5.3 | 親子紐づけ関係の登録・相関図表示・逆引き表示 | フル実装(SVGによる簡易ツリー/グラフ描画、外部グラフ描画ライブラリは導入しない) |
| 5 | 5.4 | 機微情報を保存しない方針の徹底 | DBスキーマ・APIレベルでパスワード等のカラムを設けないことで担保 |
| 6 | 5.5 | 最終ログイン日・更新期限・ステータス・2FA有無の管理 | フル実装 |
| 7 | 5.6(一部) | 休眠アカウント検出・期限切れ間近アラートのダッシュボード表示 | フル実装(アプリ内表示のみ。外部通知・メール送信は対象外) |
| 8 | 5.7(一部) | CSV/JSON エクスポート | フル実装 |
| 9 | 5.8 | カテゴリ・自由記述タグ | フル実装 |
| 10 | 6 | マスターパスワードによるアプリロック | フル実装(クライアント側のロック画面。詳細は[画面定義書](./screen_design.md)) |

## 3. v1で対象外とし、次フェーズに持ち越す機能

| # | 要件定義書の項番 | 機能 | 理由 |
|---|---|---|---|
| 1 | 5.6(一部) | パスワード使い回し・弱いパスワード警告 | パスワード値自体を保持しない設計方針(5.4)と根本的に矛盾するため、本アプリのスコープ外(要件定義書5.4に明記の通り、各パスワードマネージャー側の機能に委ねる) |
| 2 | 5.7(一部) | 他パスワード管理ツールからのインポート機能 | ツールごとにエクスポート形式が異なり個人開発では優先度が低いため次フェーズ以降で検討 |
| 3 | 5.7(一部) | 暗号化バックアップファイルの作成 | JSON/CSVエクスポートで代替。専用の暗号化フォーマットは次フェーズで検討 |
| 4 | 9.3 | Cloudflare Access によるアクセス制御 | アプリコードの範囲外(Cloudflareダッシュボード側のインフラ設定)。[構成定義書](./infra_design.md)に運用手順として記載し、Terraform等によるコード化は次フェーズで検討 |
| 5 | 9.4 | モバイルアプリ化・複数端末同期 | 要件定義書11章のオープンクエスチョンであり、v1では単一Webアプリとして提供 |

## 4. 非機能要件への対応方針(v1)

| 非機能要件 | v1での対応 |
|---|---|
| セキュリティ(パスワード非保存) | DBスキーマにパスワード保存カラムを設けない。詳細は[DB設計書](./db_design.md) |
| セキュリティ(アプリロック) | フロントエンドでマスターパスワードによるロック画面を実装。パスワードのハッシュのみを`localStorage`に保存し、平文は保持しない |
| サプライチェーンセキュリティ | 依存追加は最小限。詳細は[構成定義書](./infra_design.md)の8章 |
| 可用性(オフライン) | v1はオンライン(Cloudflare D1直結)を前提とし、オフライン編集は次フェーズで検討(要件定義書11章の今後の検討事項と合わせて扱う) |
| バックアップ | 手動エクスポート機能で対応。定期自動バックアップは次フェーズで検討 |
