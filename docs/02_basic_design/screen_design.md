## 3. 画面詳細定義

### SC-00 ロック画面

| 項目 | 内容 |
|---|---|
| 目的 | 非機能要件6章「マスターパスワードによるアプリ全体のロック」を実現する |
| 表示条件 | マスターパスワード未設定時はロック画面をスキップしダッシュボードへ。設定済みかつ未認証の場合に表示 |
| 入力項目 | マスターパスワード(1項目) |
| 動作 | `localStorage` に保存されたパスワードハッシュ(SHA-256, [処理定義書](../03_detail_design/process_design.md#マスターパスワードロック処理)参照)と入力値のハッシュを比較し、一致すればセッション(`sessionStorage`)にロック解除フラグを保存してダッシュボードへ遷移 |
| エラー表示 | 不一致時は「パスワードが違います」を表示 |

### SC-01 ダッシュボード

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書8章の通り、全体サマリーと要対応アカウントを俯瞰する |
| 表示項目 | ①登録アカウント総数 ②ステータス別件数 ③休眠アカウント一覧(最終ログインから180日以上経過) ④要確認ステータスのアカウント一覧 ⑤更新期限が30日以内のアカウント一覧 |
| アクション | 各一覧の項目クリックでSC-03(詳細)へ遷移 |

### SC-02 アカウント一覧

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書5.1「一覧表示・検索・フィルタ・ソート」 |
| 表示切替 | テーブル形式 / カード形式のトグル |
| 検索 | サービス名・識別子の部分一致検索 |
| フィルタ | カテゴリ、ステータス、ログイン方式タイプ |
| ソート | サービス名、最終ログイン日、更新期限、作成日 |
| 一覧項目 | サービス名、カテゴリ、ステータス、主要ログイン方式、最終ログイン日、更新期限 |
| アクション | 行/カードクリックでSC-03へ、「新規登録」ボタンでSC-04へ |

### SC-03 アカウント詳細

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書5.1・5.3「個別アカウントの詳細、紐づけ関係を表示」 |
| 表示項目 | 基本情報全項目、ログイン方式一覧(タイプ・プロバイダ・保存先ツール・2FA有無)、親アカウント(このアカウントが利用している認証元)、子アカウント(このアカウントを認証元として使っているもの)、タグ |
| アクション | 「編集」→SC-04、「削除」(確認ダイアログ後アーカイブ/削除)、「関係図で見る」→SC-05(当該アカウントを中心に表示) |

### SC-04 アカウント新規登録・編集

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書5.1・5.2「複数のログイン方式を持つアカウントの登録」 |
| 基本情報入力 | サービス名(必須)、識別子、カテゴリ(選択式+自由入力)、ステータス、最終ログイン日、更新期限、メモ、タグ(複数) |
| ログイン方式入力 | 「ログイン方式を追加」ボタンで行を追加。各行でタイプ選択→タイプに応じて動的に入力項目切替<br>- ID_PW: プロバイダ、パスワード保存先(選択式)、2FA有無<br>- OAuth/SNS: プロバイダ、連携に使ったアカウント(本アプリ内Accountから選択 or 自由記述)<br>- Card: プロバイダ、マスク済みコード(下4桁)、紐づけ先アカウント<br>- Device: 端末名、備考 |
| バリデーション | サービス名必須、ID_PW方式選択時はcredential_manager必須、カード番号はマスク済み4桁以内の形式チェック(処理定義書参照) |
| 保存後 | SC-03(詳細)へ遷移 |

### SC-05 紐づけ関係図(相関図)

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書5.3「紐づけ関係をツリー図・相関図として可視化」「このGoogleアカウントを失うと、どのサービスに影響するか、を逆引き表示」 |
| 表示方式 | 全アカウントをノード、`relations` を有向エッジとしたSVGグラフ(親→子の向き)。外部グラフ描画ライブラリは使用せず自前実装([処理定義書](../03_detail_design/process_design.md#紐づけ関係graphレイアウト処理)参照) |
| インタラクション | ノードクリックで当該アカウントを中心に再レイアウトし、影響範囲(子孫ノード全て)をハイライト表示。ノードダブルクリックでSC-03へ遷移 |
| 逆引き表示 | 選択ノードの祖先(親方向)/子孫(子方向)をパネルにリスト表示 |

### SC-06 設定

| 項目 | 内容 |
|---|---|
| 目的 | 要件定義書8章「マスターパスワード設定、バックアップ/エクスポート、通知設定」 |
| 機能 | ①マスターパスワードの設定・変更・解除 ②CSV/JSONエクスポートの実行・ダウンロード ③休眠判定日数・期限アラート日数のしきい値設定 ④アプリバージョン等の情報表示 |

## 4. 共通UI要素

| 要素 | 内容 |
|---|---|
| ヘッダー | アプリ名、ナビゲーション(ダッシュボード/一覧/関係図/設定) |
| ステータスラベル | 利用中(緑)/休眠(グレー)/解約済み(赤系)/要確認(黄) の色分けバッジ |
| トースト通知 | 保存・削除・エクスポート成功時の簡易通知 |

## 5. アクセシビリティ・レスポンシブ方針

- 個人利用のためモバイル最適化の優先度は高くないが、Viteの標準的なレスポンシブCSS(flexbox/grid)により、
  タブレット幅程度までは崩れないレイアウトとする。
- フォーム要素には`label`を必ず紐付け、キーボード操作のみでも一覧・詳細・登録が完結できるようにする。
