# リリースノート

## v1.0.0(初期リリース)

- リリース日: 2026-08-08
- 対応要件: [要件定義書 v0.4](../01_requirements/requirements.md) / [実装スコープ v1.0](../02_basic_design/00_implementation_scope.md)

### 実装内容

- アカウントの登録・一覧・検索・フィルタ・ソート・詳細表示・編集・削除
- 複数のログイン方式(ID/PW・OAuth・SNS・カード連携・端末紐づけ)の登録
- パスワード保存先(ツール名)の選択式記録(パスワード自体は非保存)
- アカウント間の親子紐づけ関係の登録・SVGによる相関図表示・逆引き表示(祖先/子孫)
- ダッシュボードによる休眠アカウント・要確認アカウント・更新期限間近アカウントの可視化
- カテゴリ・自由記述タグによる分類
- CSV/JSON形式でのデータエクスポート
- マスターパスワードによる簡易アプリロック
- Cloudflare Pages + Pages Functions + D1 によるサーバーレス構成
- GitHub Actionsによる CI(型チェック/テスト/ビルド/脆弱性監査)と CD(Cloudflare Pagesへの自動デプロイ)
- vitestによるユニットテスト・コンポーネントテスト(39件)
